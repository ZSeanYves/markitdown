## Behavior and remaining limits

`max_temporary_bytes` defaults to None. Some tightens the original shared
account and enables two sequential JSONL event spools. Record sources preserve
actual nonblank ordinals/physical lines. Whole-line blank facts prevent a
truncated all-space prefix from silently hiding later content; ASCII trim and
ordered optional RS/BOM semantics are pinned. Admitted nonblank records beyond
the finite route's line bound return its hard RecordLimit. Omitted records
still drain tail encoding/I/O. Ordinary grammar recovery can materialize raw
text, so this is not full bounded-memory conversion.

Loaded ObjStm charges inherited postdecode logical retention/work, including
ordinary errors; it adds no Loaded Result cache or heap/RSS guarantee. PPTX
uses actual presentation XML tokens and retains selected reference strings;
malformed XML returns its precise parse error, missing parts retain recovery,
and hard tail integrity cannot become a successful prefix result.

migration, eviction and finite production defaults remain incomplete. CLI
atomic output is outside TemporaryBytes in this freeze. CLI's final LF also
remains outside renderer output admission/confirmation: the finite Debug smoke
